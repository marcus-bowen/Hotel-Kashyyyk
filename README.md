# Hotel-Kashyyyk
## Description
Hotel Kashyyyk was a group programming project in C that I completed at BHASVIC. 
The task was to create a fully functioning hotel system with checking in, checking out and an ability to book tables.

- Learned the importance of teamwork when working on a project
- Advanced my understanding for integrating files to create a larger program
